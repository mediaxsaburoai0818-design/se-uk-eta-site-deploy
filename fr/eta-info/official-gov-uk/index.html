INFORMATIONS UK ETA

Page officielle GOV.UK pour les demandes d'UK ETA

Les demandes d'UK ETA peuvent être soumises sur le site officiel du gouvernement du Royaume-Uni ou via l'application mobile officielle.

Adresse officielle du site

Site officiel de l'UK ETA :

www.gov.uk/eta

Le domaine .gov.uk indique un site officiel du gouvernement du Royaume-Uni

Comment reconnaître le site officiel ?

  • L'URL contient gov.uk (domaine gouvernemental du Royaume-Uni)
  • Le site est géré par le Home Office
  • Les frais s'élèvent exactement à £20
  • Le site a le design caractéristique blanc et noir de GOV.UK
  • Ne demande pas de frais pour un traitement "accéléré"

Comment reconnaître un faux site ?

Signes d'avertissement :

  • L'URL ne contient pas gov.uk
  • Frais nettement supérieurs à £20
  • Promesse d'une "approbation garantie"
  • Offre de "traitement accéléré"
  • Publicité agressive ou pop-ups intrusifs
  • Absence du logo GOV.UK

Application mobile officielle

La demande d'UK ETA peut également être soumise via l'application mobile officielle "UK ETA" :

  • iOS: Recherchez "UK ETA" dans l'App Store (éditeur : Home Office)
  • Android: Recherchez "UK ETA" dans Google Play (éditeur : Home Office)
