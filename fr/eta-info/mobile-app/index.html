INFORMATIONS UK ETA

Application mobile UK ETA

Le gouvernement du Royaume-Uni a lancé l'application mobile officielle "UK ETA", qui permet de soumettre des demandes directement depuis un smartphone.

À propos de l'application UK ETA

L'application UK ETA est l'outil officiel du Home Office pour soumettre des demandes d'autorisation de voyage électronique. C'est la méthode recommandée pour soumettre des demandes, car elle permet de scanner le passeport via NFC et de remplir automatiquement les données.

Disponibilité

  • iOS (App Store)— pour les appareils Apple (iPhone). Nécessite iOS 15.6 ou ultérieur.
  • Android (Google Play)— pour les appareils Android. Nécessite Android 9.0 ou ultérieur.

Recherchez l'application sous le nom "UK ETA", éditeur : Home Office.

Fonctionnalités de l'application

  • Soumettre une nouvelle demande d'UK ETA
  • Scanner un passeport biométrique (NFC + OCR)
  • Prendre une photo du visage (selfie) pour vérification
  • Vérifier le statut d'une demande existante
  • Paiement par carte, Apple Pay ou Google Pay
  • Notifications push de changement de statut

Comment soumettre une demande via l'application ?

  1. Téléchargez l'application "UK ETA" depuis l'App Store ou Google Play
  2. Créez un compte (adresse e-mail et mot de passe)
  3. Scannez votre passeport biométrique (placez le téléphone sur le passeport)
  4. Prenez une photo de votre visage (selfie)
  5. Répondez aux questions du formulaire
  6. Effectuez le paiement de £20
  7. Envoyez la demande et attendez la décision

Scan du passeport (NFC)

L'application utilise la technologie NFC (Near Field Communication) pour lire les données de la puce biométrique du passeport. Pour scanner le passeport :

  • Ouvrez le passeport à la page de la photo
  • Placez l'arrière du téléphone sur le passeport ouvert
  • Maintenez immobile pendant 5-10 secondes
  • Attendez que l'application confirme la lecture des données

Avantages de l'application mobile

  • Scan du passeport NFC — remplissage automatique des données
  • Soumission de demande plus rapide que via le site web
  • Notifications push sur le statut de la demande
  • Sécurité biométrique (Face ID / Touch ID)
Attention :Assurez-vous de télécharger l'application officielle. Recherchez l'éditeur "Home Office" dans le magasin d'applications. Les fausses applications peuvent voler vos données personnelles.
