INFORMACIJE O UK ETA

Službena GOV.UK stranica za zahtjeve za UK ETA

Zahtjevi za UK ETA mogu se podnijeti na službenoj web stranici vlade Ujedinjenog Kraljevstva ili putem službene mobilne aplikacije.

Službena adresa web stranice

Službena web stranica za UK ETA:

www.gov.uk/eta

Domena .gov.uk označava službenu web stranicu vlade Ujedinjenog Kraljevstva

Kako prepoznati službenu web stranicu?

  • URL sadrži gov.uk (vladina domena Ujedinjenog Kraljevstva)
  • Stranicom upravlja Home Office
  • Naknada iznosi točno £20
  • Stranica ima karakterističan bijeli i crni dizajn GOV.UK
  • Ne traži naknade za "ubrzanu" obradu

Kako prepoznati lažnu web stranicu?

Znakovi upozorenja:

  • URL ne sadrži gov.uk
  • Naknade znatno veće od £20
  • Obećanje "zajamčenog odobrenja"
  • Ponuda "ubrzane obrade"
  • Agresivno oglašavanje ili nametljivi skočni prozori
  • Odsutnost GOV.UK logotipa

Službena mobilna aplikacija

Zahtjev za UK ETA također se može podnijeti putem službene mobilne aplikacije "UK ETA" :

  • iOS: Potražite "UK ETA" u App Storeu (izdavač: Home Office)
  • Android: Potražite "UK ETA" u Google Playu (izdavač: Home Office)

Druge korisne vladine web stranice

  • gov.uk/check-uk-visa— Provjerite uvjete za vizu za Ujedinjeno Kraljevstvo
  • gov.uk/standard-visitor— Informacije o standardnoj posjetiteljskoj vizi
  • uk.ambafrance.org— Veleposlanstvo Hrvatske u Londonu
  • Britansko veleposlanstvo u Varšavi
