INFORMATIONEN ZU ESTA

Transit USA: Ist für das Umsteigen eine ESTA nötig?

Ja — auch für den reinen Transit durch die USA ist eine ESTA (oder ein Visum) erforderlich. Das gilt selbst dann, wenn Sie nur an einem US-Flughafen umsteigen und Ihr eigentliches Reiseziel in einem anderen Land liegt. Die Genehmigung muss vor dem Abflug vorliegen.

Transit USA — ESTA nötig, auch ohne Aufenthalt

Wer im Rahmen des Visa Waiver Program über die USA in ein Drittland fliegt, benötigt für die Durchreise (Transit) eine gültige ESTA oder ein Visum. Es reicht nicht, erst am Flughafen darauf hinzuweisen, dass man nur umsteigt:

  • Die ESTA-Genehmigung muss vor dem Abflug vorliegen — sie wird bereits beim Boarding geprüft
  • Das gilt unabhängig davon, wie kurz der Aufenthalt am US-Flughafen ist
  • Grundlage ist die offizielle ESTA-FAQ der CBP
Planen Sie Zeit ein: Beantragen Sie die ESTA rechtzeitig vor der Reise. Wie Sie den Antrag Schritt für Schritt stellen, zeigt unsere Seite ESTA-Antrag stellen.

So füllen Sie den Antrag aus: „In Transit“ + Endziel

Der ESTA-Antrag fragt nach einer Adresse in den USA. Für reine Transitreisende gibt die CBP eine offizielle Anweisung:

  1. Geben Sie im Antrag an, dass Sie sich auf der Durchreise befinden
  2. Tragen Sie im Feld für die US-Adresse „In Transit“ ein
  3. Ergänzen Sie Ihr endgültiges Reiseziel (das Land bzw. den Ort außerhalb der USA)
Hinweis: Stellen Sie den Antrag ausschließlich über die offizielle Website esta.cbp.dhs.gov oder die offizielle App „ESTA Mobile CBP“.

Gebühr und Gültigkeit für Transitreisende

Gebühr40,27 USD pro Antrag (Stand nach der Anpassung zum Januar 2026) — auch für den reinen Transit
Gültigkeit2 Jahre — dieselbe ESTA können Sie später auch für Reisen mit Aufenthalt in den USA nutzen
ZeitpunktDie Genehmigung muss vor dem Abflug vorliegen
