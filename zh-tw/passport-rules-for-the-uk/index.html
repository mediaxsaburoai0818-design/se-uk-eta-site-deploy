入境與在英國停留

前往英國的護照規定：效期與 ETA

前往英格蘭及英國其他地區，需要一本在整個停留期間都有效的護照，而且護照與您的 ETA（£20）互相綁定。持台灣護照者，護照上必須載有國民身分證統一編號才適用 ETA。至於歐盟公民，國民身分證僅在特定情況下可以使用，例如持有 settled 或 pre-settled status 者。

護照須在整個停留期間有效

前往英國需要有效的護照，原則上護照必須在您整個停留期間都有效。

對許多國籍而言，通常沒有額外要求，例如入境後護照還須有六個月以上效期。不過規定可能因國籍而異，出發前請在 GOV.UK 確認適用於自己國籍的規定，例如使用 Check if you need a UK visa。

ETA 與護照綁定

ETA 會連結到申請時使用的護照，旅行時也必須使用申請時填寫的同一本護照。

換發或更換護照後，通常需要為新護照重新申請 ETA。因此，申請 ETA 之前最好先確認護照的效期。台灣護照還要一併確認資料頁上是否載有國民身分證統一編號；沒有的話不適用 ETA，必須辦簽證。

每位旅客都需要自己的護照——嬰兒也一樣

每位旅客，包括嬰兒和兒童，通常都需要自己的護照才能前往英國，另外也需要各自的 ETA。詳情請見 帶小孩前往英國。辦理兒童護照可能需要一些時間，請提早準備。

持有多本護照或雙重國籍

若您具有雙重國籍或持有多本護照，通常要用 ETA 所連結的那本護照入境。請確認 ETA 綁定的是您實際要使用的護照。

出發前的下一步

護照確認無誤後，就可以 申請 UK ETA，並透過 ETA 狀態查詢 追蹤申請進度。抵達後要通過 入境審查與 eGates，可攜帶入境的物品請見 英國海關規定。入境的一般規定請見 入境英國：入境規定與簽證；經英國轉機的規定另見 經英國轉機。

常見問題

前往英國時，護照效期需要多久？
前往英國通常需要一本在整個停留期間都有效的護照。對許多國籍而言，通常沒有入境後還須有六個月效期之類的額外要求，但規定可能不同。出發前請在 GOV.UK 確認適用於自己國籍的規定。
ETA 連結的是哪一本護照？
ETA 連結到申請時使用的護照，旅行時也要使用同一本護照。換發或更換護照後，通常需要為新護照重新申請 ETA。具有雙重國籍、持有多本護照者，要用 ETA 所連結的那本護照入境。
小孩前往英國也需要自己的護照嗎？
包括嬰兒在內，所有旅客通常都需要自己的護照才能前往英國，每位旅客也都需要各自的 ETA。辦理兒童護照可能需要一些時間，請及早確認相關規定。
台灣護照都可以用 ETA 入境嗎？
只有護照上載有國民身分證統一編號者適用 ETA。沒有記載者在英國的規則上屬於需要簽證的國籍，必須改辦簽證。不確定時，請用 GOV.UK 的 Check if you need a UK visa 確認。
